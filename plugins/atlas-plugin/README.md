# ATLAS Icon Bibliothek / Icon Library / Bibliothèque d’icônes ATLAS

## Deutsch

Eigenständiges ATLAS-Plugin zum Durchsuchen von Home-Assistant-Iconsets. Die Oberfläche bietet Setauswahl, Suche und ein responsives Raster mit bis zu 20 Spalten. Große Listen werden virtualisiert. Beim Anklicken eines Eintrags wird der vollständige Iconname wie `mdi:home` oder `atlas:home` in die Zwischenablage kopiert.

- **MDI:** 7.447 Icons aus Material Design Icons 7.4.47; Katalog und Lizenzangaben sind im Plugin enthalten.
- **ATLAS und andere statische Icon-Studio-Sets:** sichere Einlesung der von Icon Studio erzeugten `.js`-Dateien, vom PC oder über File Studio aus `/config/www/`.
- Die Suche in `/config/www/` und Unterordnern findet unterstützte Icon-Studio-Dateien, wenn „icon“ im Dateinamen oder einem Ordnernamen vorkommt. Dazu gehören auch Community-Ordner wie `/config/www/community/` (in Home Assistant unter `/local/community/` erreichbar). Dateien desselben Präfixes werden zusammengefasst.
- **Auflistbare Home-Assistant-Sets:** Legacy-Sets werden erkannt, wenn sie die Home-Assistant-Schnittstelle `window.customIcons` mit `getIconList()` und `getIcon()` bereitstellen.

Home Assistant bietet für die moderne `window.customIconsets`-Schnittstelle keinen allgemeinen Aufruf, um alle Iconnamen eines Sets abzufragen. Solche Sets können nur angezeigt werden, wenn sie zusätzlich eine Namensliste bereitstellen oder als unterstützte statische Icon-Studio-Datei importiert werden. Das Plugin führt fremden JavaScript-Code nicht aus. Für File-Studio-Zugriff muss `/config/www` freigegeben sein. Importierte Sets bleiben lokal in IndexedDB gespeichert; ein Home-Assistant-Token wird nicht benötigt.

## English

Standalone ATLAS plugin for browsing Home Assistant icon sets. The interface provides set selection, search and a responsive grid with up to 20 columns. Large lists are virtualized. Clicking an item copies its fully qualified name, such as `mdi:home` or `atlas:home`, to the clipboard.

- **MDI:** 7,447 icons from Material Design Icons 7.4.47; the catalog and license information are bundled.
- **ATLAS and other static Icon Studio sets:** safely import `.js` files generated by Icon Studio, from the PC or through File Studio from `/config/www/`.
- The scan searches `/config/www/` and its subfolders for supported Icon Studio files when “icon” appears in the filename or a folder name. This includes community folders such as `/config/www/community/` (available in Home Assistant under `/local/community/`). Files using the same prefix are combined.
- **Listable Home Assistant sets:** legacy sets are detected when they expose Home Assistant's `window.customIcons` interface with `getIconList()` and `getIcon()`.

Home Assistant's modern `window.customIconsets` interface has no general method for listing every icon name in a set. Such sets can only be displayed when they also provide a name list or are imported as a supported static Icon Studio file. The plugin does not execute third-party JavaScript. File Studio must allow `/config/www` for direct file access. Imported sets are stored locally in browser IndexedDB; no Home Assistant token is required.

## Français

Plugin ATLAS indépendant pour parcourir les jeux d’icônes Home Assistant. L’interface propose la sélection du jeu, la recherche et une grille adaptative pouvant afficher jusqu’à 20 colonnes. Les grandes listes sont virtualisées. Un clic copie l’identifiant complet, par exemple `mdi:home` ou `atlas:home`, dans le presse-papiers.

- **MDI :** 7 447 icônes de Material Design Icons 7.4.47 ; le catalogue et les informations de licence sont inclus.
- **Jeux ATLAS et autres jeux statiques Icon Studio :** importation sécurisée des fichiers `.js` créés par Icon Studio, depuis le PC ou via File Studio depuis `/config/www/`.
- La recherche parcourt `/config/www/` et ses sous-dossiers à la recherche de fichiers Icon Studio compatibles lorsque « icon » figure dans le nom du fichier ou d’un dossier. Cela inclut les dossiers communautaires comme `/config/www/community/` (accessible dans Home Assistant sous `/local/community/`). Les fichiers utilisant le même préfixe sont regroupés.
- **Jeux Home Assistant listables :** les jeux historiques sont détectés s’ils exposent l’interface Home Assistant `window.customIcons` avec `getIconList()` et `getIcon()`.

L’interface moderne `window.customIconsets` de Home Assistant ne fournit aucune méthode générale pour obtenir la liste complète des noms d’un jeu. Ces jeux ne sont affichés que s’ils fournissent également une liste de noms ou s’ils sont importés comme fichiers statiques Icon Studio compatibles. Le plugin n’exécute pas de code JavaScript tiers. L’accès direct nécessite d’autoriser `/config/www` dans File Studio. Les jeux importés sont stockés localement dans IndexedDB du navigateur ; aucun jeton Home Assistant n’est nécessaire.

## Development

```sh
npm run build
npm run check
npm test
```

The build bundles the generated plugin package and repository catalog. The included MDI catalog is from `@mdi/svg` 7.4.47; its source license is preserved in `mdi-icons.json`.
